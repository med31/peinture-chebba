# 20 — Glossaire (tous les sigles de l’offre)

Lis-le en diagonal. Chaque entrée tient en **une phrase humaine**.

| Mot | Signification |
|---|---|
| **AA** | Niveau WCAG visé par beaucoup de sites : plus strict que A, moins que AAA. |
| **AC** | Acceptance Criteria : les « c’est fini quand ». |
| **API** | Contrat d’échange entre programmes (front ↔ back). |
| **ARIA** | Attributs HTML pour aider les technologies d’assistance quand le HTML natif ne suffit pas. |
| **BDD** | Behavior Driven Development : tests racontés en langage métier (Given/When/Then). |
| **BEM** | Convention de noms CSS : Block__Element--Modifier. |
| **BFF** | Backend For Frontend : API adaptée au front, agrège les micro-services. |
| **BGPN** | Branche Grand Public et Numérique du Groupe La Poste. |
| **CDN** | Réseau de serveurs proches de l’utilisateur pour servir fichiers / HTML vite. |
| **CI/CD** | Intégration continue / déploiement continu. |
| **CLS** | Mesure de « la page qui saute » pendant le chargement. |
| **Composable** | Fonction Vue `useX` qui encapsule de la logique réactive réutilisable. |
| **Composition API** | Style Vue 3 (`ref`, `computed`, `<script setup>`). |
| **CORS** | Règle navigateur qui limite les appels HTTP vers un autre domaine. |
| **CSR** | Rendu uniquement dans le navigateur (SPA). |
| **CSS** | Langage de style. |
| **Cypress** | Outil de tests bout-en-bout dans un vrai navigateur. |
| **Devtools** | Outils du navigateur / Vue / Pinia pour inspecter. |
| **Docker** | Empaqueter l’app dans un conteneur reproductible. |
| **DOM** | Arbre d’objets de la page, manipulé par le navigateur et Vue. |
| **DoD** | Definition of Done : checklist qualité d’un ticket. |
| **DS** | Design System. |
| **DSI** | Direction des Systèmes d’Information. |
| **DT** | Direction Technique (ici eCommerce). |
| **Emit** | L’enfant Vue prévient le parent (« add », « update:query »). |
| **ESLint** | Analyseur de qualité de code. |
| **ESM** | Modules JavaScript natifs (`import` / `export`). |
| **Fetch** | Fonction navigateur pour appeler une HTTP API. |
| **Figma** | Outil de maquettes / DS. |
| **Frontify** | Plateforme de marque / documentation DS. |
| **Git** | Historique du code. |
| **GitLab** | Forge (dépôt, MR, CI) citée dans l’offre. |
| **GraphQL** | Langage de requête API : une URL, tu choisis les champs. |
| **HTML** | Structure de la page. |
| **HTTP** | Protocole des requêtes web (GET, POST, codes 200/404/409…). |
| **Hydration** | Nuxt/Vue rattache les événements au HTML déjà envoyé par le serveur. |
| **INP** | Mesure de réactivité au clic / frappe. |
| **Invision** | Ancien outil de prototype cliquable. |
| **ISR / SWR** | Régénérer / servir du HTML en cache puis le rafraîchir. |
| **Jest** | Runner de tests unitaires (historique). |
| **JSON** | Format texte d’objets, standard des API. |
| **JSX** | Syntaxe HTML-dans-JS (surtout React). Vue utilise surtout des templates. |
| **LCP** | Quand le plus gros contenu visible s’affiche. |
| **MR** | Merge Request GitLab. |
| **Nuxt** | Framework au-dessus de Vue : routes fichiers, SSR, conventions. |
| **Options API** | Ancien style Vue (`data`, `methods`). |
| **Pinia** | Store officiel Vue 3. |
| **PO** | Product Owner : priorise le métier. |
| **Prettier** | Formateur de code automatique. |
| **Props** | Données parent → enfant, en lecture seule. |
| **Proxy** | Mécanisme JS utilisé par Vue 3 pour la réactivité. |
| **QA** | Quality Assurance : recette / tests métier. |
| **ref** | Boîte réactive Vue. En script : `.value`. |
| **REST** | Style d’API : URL + verbes HTTP. |
| **RGAA** | Référentiel français d’accessibilité, dérivé WCAG. |
| **Rollup** | Bundler utilisé par Vite en production. |
| **RUM** | Mesure de perf chez les vrais utilisateurs. |
| **SAFe** | Cadre Agile à l’échelle de plusieurs équipes. |
| **SASS / SCSS** | Préprocesseur CSS (variables, nesting). |
| **Scrum** | Cadre Agile (sprints, daily, revue, rétro). |
| **SEO** | Être trouvable et compréhensible par les moteurs de recherche. |
| **SPA** | Single Page Application : un HTML, le JS change les vues. |
| **SSR** | Le serveur fabrique le HTML avant de l’envoyer. |
| **SSG** | HTML généré au build (statique). |
| **SKU** | Référence produit (id d’offre). |
| **Storybook** | Galerie de composants isolés. |
| **TDD** | Écrire le test avant le code (red/green/refactor). |
| **TS** | TypeScript. |
| **useFetch** | Composable Nuxt : GET SSR-friendly. |
| **Vite** | Bundler / dev server moderne (Vue 3, Nuxt 3). |
| **Vitest** | Jest-like pour Vite (ce kit). |
| **Vue** | Framework UI. |
| **Vue Router** | Routes côté client. |
| **Vuex** | Ancien store Vue 2. |
| **WCAG** | Recommandations d’accessibilité web (ici 2.1). |
| **Webpack** | Bundler historique (Nuxt 2, Vue CLI). |
| **XSS** | Attaque : injecter du JS via du HTML non filtré. |
