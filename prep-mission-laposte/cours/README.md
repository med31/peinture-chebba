# Cours — tout comprendre sans chercher ailleurs

Lis **dans l’ordre**. Chaque chapitre suppose que tu as lu les précédents. Les mots techniques sont définis la première fois. Les exemples parlent toujours d’un site La Poste (acheter un colis, un carnet de timbres, un carton).

Tu n’as **pas** besoin d’ouvrir Google. Si un mot te manque, va au [glossaire](20-glossaire.md).
